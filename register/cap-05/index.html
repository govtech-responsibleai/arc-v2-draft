CAP-05 · Official Communication

CAP-05Interaction capability

The capability to compose, finalise, and dispatch authoritative communications that formally and legally represent an organization to external parties (e.g. customers, partners, regulators, courts, or media) via approved channels and formats, thereby creating potential legal, regulatory, or reputational obligations. This includes sending legally binding correspondence, publishing official statements or press releases, and responding to external inquiries using the organisation's identity. A system has this capability whether a person sends what the agent drafts, approves each message before it goes, or lets the agent send by itself; that difference is recorded as the capability's authority.

A system with this capability carries 2 risks from it, and 0 more when it also has the other elements listed. Together they carry 2 Level 0 controls. See what applies to a system with this capability.

How it is used

Section titled “How it is used”

An assessment records the authority this capability is used at: propose, act with approval and act alone. By definition, its effects cannot be undone and its effects reach outside the organisation. Where any of this is not stated, the most cautious case is assumed. See how a capability is used.

Controls that are stricter in some uses:

  • CTRL-0042 · Require explicit human confirmation before executing high-impact or irreversible tool actions: Level 0 where a capability is used at act alone, and its effects cannot be undone and reach outside the organisation
  • CTRL-0043 · Log all tool selection decisions and invocations with comprehensive metadata: Level 0 where a capability is used at act alone

In combination rules

Section titled “In combination rules”

Some risks arise when capabilities together complete a dangerous combination. This capability can supply:

  • Untrusted content for the Lethal trifecta rule (in some systems): Yes if it also reads replies or other inbound messages on the channels it sends through.
  • Outbound channel for the Lethal trifecta rule (yes, when used at act with approval or above): It sends messages to people outside the organisation.
